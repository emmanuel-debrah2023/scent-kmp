## Numbering

Numbers are assigned in the order ADRs are written and never reused. ADR-0003 is
the A2UI client engine, so the server-driven Fragrance Detail ADR will be
**ADR-0004** (written on its own branch, so it is missing from this table until that merges). Check this table and open branches before numbering a new one.
